# CSC207_Project
Team Project for CSC207

Sudoko Game App

User Story  
As a player, I would like to choose different difficulty levels. 
As a player, I want to keep track on my game history / records (which contains the time and score).  
As a player, I would like to have my own account to keep the score.    
  
Use cases  
create an account & log in  
generate Sudoku puzzle (base on difficulty level)  
timer  
calculate the score  

API  
Sudoku100 (embeded interactive game)  
Dosuku  
Sugoku
